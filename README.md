# 🚗 Used Car Price Prediction System

## 📌 Overview
The Used Car Price Prediction System is a machine learning project that predicts the resale price of used cars based on historical vehicle data. The model helps estimate fair market value using key car attributes.

---

## 🎯 Objectives
- Predict resale price of used cars
- Analyze factors influencing car valuation
- Apply regression-based machine learning models
- Support data-driven pricing decisions

---

## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

---

## 🚘 Features
- Car Brand
- Model
- Manufacturing Year
- Mileage (KMs Driven)
- Fuel Type
- Transmission
- Owner Type

---

## ⚙️ Machine Learning Models
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor

---

## 📊 Model Evaluation
- R² Score
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
